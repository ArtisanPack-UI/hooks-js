# ArtisanPack UI Hooks (JS) Documentation

Welcome to the documentation for `@artisanpack-ui/hooks-js` — WordPress-style actions and filters for JavaScript, with a first-class React adapter.

This package is the JavaScript counterpart to [`artisanpack-ui/hooks`](https://github.com/ArtisanPack-UI/hooks) for PHP. The two share a naming convention (`ap.<domain>.<event>`, dot-notation lowerCamelCase) and identical semantics for priorities, dedup, and deprecation aliases — so a hook you know from the PHP side behaves the same in the browser.
